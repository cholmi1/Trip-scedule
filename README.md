# TripCost · 가성비 최강 여행계획

목적지·기간·인원·예산을 입력하면 **최저가 항공 → 도심 숙박 → 맛집 동선 → 교통패스 → 예산 대시보드**까지
예산 안에서 가장 만족도 높은 여행 계획을 자동으로 짜주는 웹앱입니다.

모든 금액은 **KRW(원)** 로 표시되며, 한국어 UI 기준입니다.

## 화면 구성 (6개 탭)

| # | 탭 | 내용 |
| --- | --- | --- |
| 0 | 검색 헤더 | 여행지 자동완성, 날짜 선택기, 인원수, 예산 슬라이더(30만~300만원), 출발 공항, **가성비 계획 짜기** 버튼 |
| 1 | 항공 | 왕복 최저가 **3개 비교**, 직항/경유 구분, 예상 비행시간, 저가항공 여부, 수하물, 출처(Skyscanner/Amadeus), **1인/총액 토글**, 출발일 ±3일 최저가 탐색 막대 그래프 |
| 2 | 숙박 | 호텔/게스트하우스/에어비앤비 구분 카드, 평점 8.0 이상, 도심 1km 이내 우선, 1박당 가격, 총 숙박비 자동 계산 |
| 3 | 일정·관광 | 일자별 타임라인, 오전/오후/저녁 구분, 관광지 + 점심 맛집 + 카페 + 저녁 로컬 식당, 각 장소별 소요시간·입장료·이동시간·이동수단 |
| 4 | 현지 교통 | 공항→시내 이동 옵션 비교(Rome2Rio 로직), 시내 교통패스 비교, 이동수단 아이콘 시각화, 일자별 교통비 배분 |
| 5 | 지도 | Leaflet/OpenStreetMap 기반 숙소 + 방문 장소 동선 (SSR 회피 처리) |
| 6 | 예산 대시보드 | 파이차트(지출 비율), 막대그래프(실제 vs 권장 비중), 항목별 금액, 예산 대비 사용률, **절약 팁 3가지**, 종합 가성비 점수 |

추가로 다크모드, PDF/PNG 내보내기, 공유(Web Share API · 클립보드 폴백), 모바일 퍼스트 반응형 레이아웃을 제공합니다.

## 가성비 최적화 로직 (`src/lib/engine.ts`)

1. **항공** — 요청 날짜 기준 **±3일(7일)** 을 전부 조회해 최저가 날짜를 선택합니다.
   시드 기반 결정적 난수(`mulberry32`)를 사용해 같은 입력 → 같은 결과가 보장됩니다(SSR/CSR 불일치 방지).
2. **숙박** — 평점 8.0 이상 → 도심 1km 이내(부족 시 1.5km → 3km로 완화) → **평점 내림차순, 가격 오름차순** 정렬.
   실제 추천은 `(평점/10) ÷ (야간가/10만원)` 비율이 가장 좋은 **가성비 1위** 숙소입니다.
3. **일정** — 오전 관광지 → 오후 관광지 + 점심 맛집 + 카페 → 저녁 이자카야/로컬 식당.
   1km 미만 구간은 자동 도보 처리해 교통비를 아낍니다.
4. **교통** — 공항 이동(왕복 2회) + 시내 패스 조합으로 1인 교통비 합산.
5. **예산** — 항공 40% / 숙박 35% / 식비 15% / 교통 10% 기준과 실제 비중을 비교.
6. **종합 점수**

   ```
   score = (관광지 만족도 × 0.4 + 맛집 평점 × 0.3) ÷ 1인 총비용 × 100
   ```

   만족도·평점은 10점 척도로 정규화하고, 비용은 10만원 단위로 스케일링합니다.

## 데이터 구조 (`src/data`)

| 파일 | 내용 |
| --- | --- |
| `catalog.json` | **목적지 카탈로그 115곳** — 좌표, 공항, 동네, 성수기, 1인 왕복 최저가 기준, 비용 티어 |
| `cities.json` | 큐레이션 도시 7곳 (도쿄·오사카·교토·파리·로마·방콕·제주) — 좌표, 공항, 동네, 시즌 |
| `stays.json` | 큐레이션 도시별 숙소 6~8개 (호텔 / 게스트하우스 / 에어비앤비) |
| `places/{city}.json` | 큐레이션 도시별 관광지 · 맛집 · 카페 (좌표, 평점, 입장료, 소요시간) |
| `transport.json` | 큐레이션 도시별 공항 이동 수단 + 시내 교통패스 |

**목적지 선택 (`src/components/search/SearchHeader.tsx`)**
- 총 **122곳**(큐레이션 7 + 카탈로그 115)을 검색합니다.
- 한글명·영문명·국가·**동네명**·공항 코드로 찾을 수 있습니다. (`도쿄`, `Japan`, `신주쿠`, `HND`)
- 검색어가 없으면 인기 도시 칩 + 전체 목록, 검색어가 있으면 매칭 도시만 표시합니다.
- 카드에 `실제 장소` / `일반 가이드` 배지로 데이터 정확도를 표시합니다.
- 홈 화면의 **목적지 브라우저**에서 10개 지역 필터로 둘러볼 수 있습니다.

**도시 추가 방법**: `catalog.json` 에 항목 하나만 추가하면 됩니다.
좌표·공항·운임만 정확하면 항공·교통·예산은 즉시 계산되고,
장소·숙박은 비용 티어 기반 일반 가이드가 자동 생성됩니다.

## 일반 가이드(synthetic) 데이터

큐레이션 데이터가 없는 도시에도 모든 탭이 동작하도록 `src/lib/data.ts` 의
`buildSyntheticPlaces` / `buildSyntheticStays` / `buildSyntheticTransport` 가
도시 좌표·동네·비용 티어에서 **결정적으로** 데이터를 생성합니다.

| 항목 | 계산 근거 |
| --- | --- |
| 항공 운임 | 도시 `fare`(없으면 거리 기반 파워 법칙) × 항공사 계수 × 성수기 × 요일 × 노이즈 |
| 비행시간 | 대권 거리 ÷ 800km/h + 50분 (경유 시 ×1.55~1.85) |
| 식사비 | 도시 1일 식사 예산(`avgFoodCost`) × 유형별 1끼 비율(0.18~0.85) |
| 입장료 | 도시 1일 입장료 예산(`avgTicketCost`) × 유형별 비율(0~0.35) |
| 숙박 | 1일 식사 예산 × 2.6 × 숙소 등급 배수(0.4~2.1) |
| 교통 | 비용 티어별 공항 이동·시내 패스 요금표 |

생성된 장소는 **실제 업소가 아닌 유형 가이드**이므로, UI 에 `일반 가이드` 배지와
안내 문구를 표시합니다. 실제 방문 전 반드시 확인해야 합니다.

## 실제 API 연동

현재 모든 데이터는 목(mock)이며, 연동은 `src/lib/engine.ts` 와 `src/lib/data.ts` 만 교체하면 됩니다.

| 항목 | 파일 | 비고 |
| --- | --- | --- |
| 항공 | `generateFlightOffers()` | Amadeus `Shopping Flight Offers` 또는 Skyscanner `flightSearch` 응답을 `FlightOffer`로 매핑 |
| 장소 | `getAttractions()` / `getRestaurants()` / `getCafes()` | Google Places Text Search + Place Details |
| 숙박 | `getStays()` | Booking.com Demand API |
| 지도 | `ItineraryMap.tsx` | TileLayer URL을 Google Maps SDK로 교체 |

환경 변수는 `.env.example` 참고 (`AMADEUS_API_KEY`, `GOOGLE_PLACES_KEY`, `SUPABASE_URL` 등).
